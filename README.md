# 仓跑巴士 · 仓鼠跑酷地图

《守望先锋》破坏球（仓鼠）自定义房间跑酷地图合集站。数据内嵌在单个 `index.html` 中，无需任何依赖，浏览器直接打开即可使用。

## 功能
- 209 条地图代码，按代码去重
- 难度 / 地图 / 作者筛选 + 关键词搜索
- 地图代码一键复制
- 支持下载 CSV 模板并导入 / 更新数据
- 管理员密码门禁：默认密码 `admin2026`，登录后可在「导入数据」面板中修改

## GitHub Pages 部署步骤（约 3 分钟）
1. 打开 https://github.com/new 新建仓库（Public 即可，名字随意，如 `hamster-parkour`），**不要**勾选"Add a README file"。
2. 进入新仓库页面 → 点 **Add file → Upload files**。
3. 把本目录下的 `index.html` 拖入上传区，点 **Commit changes**。
4. 点仓库页顶部 **Settings** → 左侧菜单选 **Pages**。
5. **Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
6. 等 1~2 分钟，页面顶部会出现你的站点地址 `https://<用户名>.github.io/<仓库名>/`，访问即上线。

## 提醒
- 管理员密码是纯前端门禁（localStorage 校验），用于挡住普通访客；如需真正的服务端鉴权可再升级。
- 首次部署后建议立刻登录并修改默认密码 `admin2026`。
